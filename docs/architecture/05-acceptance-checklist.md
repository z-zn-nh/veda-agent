# 05 验收清单

## 阶段 0：项目与命名

- [ ] 新项目有独立目录和单一启动命令。
- [ ] 产品正式名称未确定时，包名、应用标识、CSS 前缀、存储 key 使用中性占位符。
- [ ] 代码中没有把旧项目产品名当作新产品名。
- [ ] 类型检查命令可运行。
- [ ] 至少有一组单元或契约测试可运行。

## 阶段 1：Haze 与占位运行时

- [ ] Haze 的仓库、包名、版本和兼容范围有记录。
- [ ] 真实 Haze API 只出现在 UI 适配层。
- [ ] Haze 不可用时应用可以使用不透明材质启动。
- [ ] 支持浅色、深色和减少透明度的降级策略。
- [ ] Agent 面板显示明确的“运行时未接入/占位”状态。
- [ ] 没有导入猜测的 pi 或 Agent SDK。

## 阶段 2：工具栏与布局

- [ ] 顶部有独立的 Agent、笔记、白板入口。
- [ ] 入口操作是打开、定位或创建面板，不是整页模式切换。
- [ ] 单栏可打开任意一种面板。
- [ ] 双栏可打开任意两种面板组合。
- [ ] 至少三栏可通过同一布局树创建。
- [ ] 支持横向和纵向分割。
- [ ] 支持比例调整、标签组、关闭和恢复。
- [ ] 同类面板可以同时打开。
- [ ] 面板焦点唯一且可见。
- [ ] 删除、撤销、保存等快捷键只作用于活动面板。
- [ ] Haze 透明、模糊和阴影没有覆盖高频画布内容。

## 阶段 3：独立笔记与白板

- [ ] 不配置模型即可创建和编辑笔记。
- [ ] 不启动 Agent 即可保存和重开笔记。
- [ ] 不配置模型即可创建和编辑白板。
- [ ] 白板可以直接创建原生文本、便签、图形或线条。
- [ ] 白板可以创建笔记引用。
- [ ] 删除引用不删除目标笔记。
- [ ] 目标笔记缺失时显示占位，不静默删除引用。
- [ ] 笔记正文只有一个权威来源。
- [ ] 白板文档只有一个权威来源。
- [ ] 保存中、保存失败、冲突和恢复状态可见。
- [ ] 切换或关闭面板时不会静默丢失脏数据。

## 阶段 4：能力迁入

- [ ] 编辑器能力通过新笔记服务接入，不直接依赖旧总控制器。
- [ ] 画布能力通过新白板服务和适配层接入。
- [ ] 画布键盘事件限定在活动面板范围。
- [ ] 旧数据模型与新模型之间有明确转换记录。
- [ ] 迁移失败不会破坏源数据。
- [ ] 旧工程与新工程不会长期维护同一功能的两份真源。

## 阶段 5：共享会话

- [ ] GUI 和 TUI 使用同一 `sessionId` 时只有一个执行器。
- [ ] 会话有快照和事件序号。
- [ ] 客户端重连后可以恢复状态。
- [ ] 请求带客户端 ID 和请求 ID，可去重。
- [ ] 取消请求绑定具体运行 ID。
- [ ] 一个客户端断开不会静默杀掉会话。
- [ ] 执行器中断会显示为中断或失败，不伪装成完成。
- [ ] Agent 可以读取笔记和白板结构。
- [ ] Agent 可以通过应用服务修改笔记和白板。
- [ ] Agent 修改能通知已打开的 GUI 面板。
- [ ] Agent 修改与用户修改冲突时不会静默覆盖。

## 阶段 6：迁移与发布

- [ ] 使用源数据副本完成转换。
- [ ] 备份流程处理数据库一致性和正在写入的日志文件。
- [ ] 笔记正文、白板对象、引用和附件数量有迁移前后对照。
- [ ] 应用级草稿、阅读状态和恢复数据有单独处理方案。
- [ ] 能生成迁移报告。
- [ ] 能失败后重试或回滚。
- [ ] 新项目在空数据、旧数据和缺失附件情况下都能启动。
- [ ] 产品正式名称确定后，才执行一次性品牌和标识替换。
